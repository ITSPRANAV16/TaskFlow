## 🌟 Features

- 📝 **Task Management (CRUD)**: Create, edit, search, and delete tasks effortlessly.
- 📋 **Subtasks / Checklists**: Break down complex tasks into manageable subtask checklist items.
- 🚦 **Priority Levels**: Categorize tasks by priority (**Low 🟢, Medium 🟡, High 🔴, Urgent 🟣**).
- 🏷️ **Category Tagging**: Filter tasks by categories (*Work, Personal, Study, Health, Shopping, Finance, Other*).
- 📊 **Productivity Analytics**: Interactive dashboard with real-time completion progress bars and status cards.
- 🔄 **GitHub In-App Auto Update**: Automatic background check for new releases with one-tap update prompt.
- 💾 **Local Data Persistence**: Fast, offline-first data storage using `SharedPreferences`.
- 🎨 **Adaptive Responsive Design**: Supports Android mobile view and Windows Desktop multi-pane layouts.
- 🌙 **Dark & Light Mode**: Curated HSL Indigo/Teal theme powered by Google Fonts (*Outfit & Inter*).

## 🛠️ Tech Stack & Architecture

- **Framework**: [Flutter SDK](https://flutter.dev)
- **Language**: [Dart](https://dart.dev)
- **State Management**: [Provider](https://pub.dev/packages/provider)
- **Local Storage**: [SharedPreferences](https://pub.dev/packages/shared_preferences)
- **Typography**: [Google Fonts](https://pub.dev/packages/google_fonts) (*Outfit & Inter*)

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed (version >= 3.0.0)
- [Dart SDK](https://dart.dev/get-started) installed

### Installation & Run

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ITSPRANAV16/TaskFlow.git
   cd TaskFlow
   ```

2. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run on Desired Device**:
   - **Chrome Web**:
     ```bash
     flutter run -d chrome
     ```
   - **Windows Desktop**:
     ```bash
     flutter run -d windows
     ```
   - **Android Mobile**:
     ```bash
     flutter run
     ```

4. **Build Production APK**:
   ```bash
   flutter build apk --debug --target-platform android-arm64
   ```
